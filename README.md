정식 명칭은 **Artemis**입니다. 저장소와 로컬 폴더의 기존 이름은 유지합니다.

## 초기 구상 — 2026-10-28

| 항목 | 현재 방향 | 결정 상태 |
|------|-----------|-----------|
| 제품 | 멀티 에이전트 기반 복합 개발 하네스 | 기본 방향 확정 |
| LLM 실행·연결 | GPT 계열 모델을 Codex와 OAuth 인증을 통해 사용하는 방식 검토 | 후보, 모델과 연결 방식 미확정 |
| 메모리 | 작업 기억·공유 기억·거시 기억을 연결 | 큰 틀 정리 중, 세부 방식 미정 |

### LLM

GPT/Codex의 OAuth 연결을 후보로 검토합니다. 모델과 인증·연결 방식은 추후 결정하며, 실제 연결은 아직 검증하지 않았습니다.

후속 검토 참고: [공식 Codex app-server OAuth 연동 문서](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server).

### 메모리의 큰 틀

| 구분 | 역할 |
|------|------|
| 작업 기억 | 각 에이전트가 현재 작업의 맥락과 진행 내용을 유지 |
| 공유 기억 | 에이전트 간 결과·발견 사항·인계 내용을 공유 |
| 거시 기억 | Obsidian으로 프로젝트 목표·주요 결정·전체 흐름을 정리 |

작업에서 나온 내용을 공유하고, 중요한 내용을 거시 기억에 반영합니다. 새 작업에서는 거시 기억과 관련 공유 기억을 참고합니다.

저장소, 검색 기술, 동기화 방식, 데이터 구조와 충돌 처리는 후속 상세 설계에서 다룹니다.

기존 [세부 메모리 조사](docs/memory-architecture.md)는 후속 참고자료로 보존합니다. 해당 문서의 기술 제안은 1차 기획의 결정 사항에 포함하지 않습니다.
