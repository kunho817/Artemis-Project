### Codex OAuth 연결 후보

2026-10-28 기준 공식 OpenAI 문서에는 Sign in with ChatGPT의 사용 권한을 받아 OAuth 토큰으로 Codex app-server를 연결하는 경로가 안내되어 있습니다. 따라서 Artemis의 연결 후보로 검토할 수 있습니다. 이 문서는 오픈소스·로컬 호스팅 앱을 대상으로 하며, 유료 또는 원격 호스팅 앱은 별도 문의 경로를 안내합니다. Artemis의 배포 형태는 아직 결정하지 않았습니다.

실제 연결 가능 여부는 계정 권한과 선택 모델로 요청을 완료해 확인해야 합니다. 토큰 갱신, 사용 한도와 지원 도구 제약도 구현 전에 확인합니다. 현재 인증 설정이나 실제 추론 테스트는 진행하지 않았습니다.

### 메모리 설계에서 알아볼 내용

Obsidian에 정리할 거시 기억의 예시는 프로젝트 목표, 주요 결정과 이유, 진행 상황입니다. 이는 정리 대상의 초안이며 세부 규칙은 아직 정하지 않았습니다.

세부 기억은 작업 이력, 코드·파일 참조, 실행 결과 등을 어디에 보관하고 어떻게 찾아올지 조사합니다. 원본 기록과 요약의 연결, 기억 갱신 시점, 에이전트 간 공유 범위도 함께 검토합니다. 특정 데이터베이스나 검색 기술은 아직 선택하지 않았습니다.
